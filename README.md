# M Venkata Kishore Reddy — Portfolio

A modern, high-performance developer portfolio showcasing full-stack web applications, engineering skills, and real-world projects.

## Live Site
🔗 [https://myportfolio-ten-mocha-81.vercel.app](https://myportfolio-ten-mocha-81.vercel.app)

## Tech Stack
- **React 19**
- **Vite**
- **Tailwind CSS 4**
- **Framer Motion**
- **AOS (Animate on Scroll)**
- **EmailJS**
- **WebGL** (Fluid Splash Cursor Simulation)

## Run Locally

Clone the repository and install dependencies:

```bash
npm install
```

Start the local development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

## Environment Variables

Create a `.env.local` file in the root directory to enable direct form submissions via EmailJS:

```env
VITE_EMAILJS_SERVICE_ID=
VITE_EMAILJS_TEMPLATE_ID=
VITE_EMAILJS_PUBLIC_KEY=
```

*(If omitted or unconfigured, the contact form automatically falls back to an interactive email client mailto compose window).*
